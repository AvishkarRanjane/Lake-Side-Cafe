A modern, responsive e-commerce web application for **Lake Side Café & Eatery** located in New Panvel, Maharashtra. Built with a rich dark-forest & amber aesthetic, featuring a real-time interactive food menu, live search & category filtering, 3D interactive model preview, persistent shopping cart, and direct WhatsApp order checkout.

---

## ✨ Features

- 🎨 **Luxury Aesthetic & Responsive Design:** Custom dark-forest green (`#013220`) and amber (`#FFBF00`) theme with glassmorphic cards and micro-animations.
- 🍲 **Interactive Menu & Category Filters:** Instantly filter dishes across Veg Soups, Non-Veg Soups, Salads, Main Course, Burgers, Pastas, and Beverages.
- 🔍 **Live Search Bar:** Real-time search by dish name or description.
- 🛒 **Persistent Shopping Cart:** Add to cart, adjust quantities, calculate subtotal, 5% GST, and delivery fees stored securely in `localStorage`.
- 📱 **Direct WhatsApp Order Checkout:** Auto-generates a formatted WhatsApp order summary sent directly to the cafe's ordering hotline.
- 📦 **Structured Asset Organization:** Web-optimized AVIF/WebP image assets neatly organized in `assets/images/`.

## 🚀 Local Development Setup

1. **Clone the repository:**
   ```bash

   cd Lake-Side-Cafe
   ```

2. **Open with Live Server:**
   - Open `index.html` in any web browser or start a local HTTP server (e.g. VS Code Live Server).
